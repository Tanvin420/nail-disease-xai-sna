# Cross-dataset results on the shared labels only

_Generated by `scripts/s07b_shared_label_matrix.py` from `results/predictions/`. Provisional until the manuscript numbers are taken from `results/macros.tex`._

**How each cell is computed.** Train on dataset X, test on dataset Y. Only the classes that **both** X and Y have are used: test images of other classes are dropped, and the model may choose only among the shared classes. Values are the mean over the 5 architectures (ko-pin row: each architecture first averaged over its 15 group-disjoint cv runs; other rows: one run per architecture). `own_test` = held-out part of the training dataset itself. `*` = fewer than 30 test images, unreliable. `–` = not available, or fewer than 2 shared classes (accuracy/F1 would be meaningless).

Note that images already linked to the training dataset (copies) have been removed from every target, and that the restricted choice is optimistic compared with letting the model choose among all 7 classes (see `results/metrics/xsrc_matrix.csv`, strict columns).

## How to read these tables

- Compare cells only when the number of shared classes is the same. A 2-class task (for example healthy vs onychomycosis) is much easier than a 5-class task, so a high value from a dataset with few classes does not mean a better model. For this reason no row averages are given.
- Fair comparison for a given test dataset: look down one column and check the shared-class table above for equal counts.
- Own-test values of 2-class datasets (nikhilgurav21, josephrasanjana: 0.98-0.99) are easy binary tasks.
